# Academic homepage

A minimal, multi-page academic website ready for GitHub Pages.

## Preview locally
Open `index.html` in a browser.

## Publish
1. Create a public repository named `YOUR-USERNAME.github.io`.
2. Upload all files from this folder to the repository root.
3. In GitHub: Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
4. Visit `https://YOUR-USERNAME.github.io`.

## Personalize
- Replace `Your Name`, university, email, research and publication placeholders in the HTML files.
- To add a photo, replace the `.portrait` placeholder in `index.html` with `<img class="portrait" src="portrait.jpg" alt="Portrait of Your Name">` and put `portrait.jpg` beside `index.html`.
- Add your CV as `cv.pdf` beside `cv.html`.
- Replace placeholder `href="#"` paper links with actual URLs.

Research and publications are combined in `research.html`.
